학습 — 마감마다 전부 다시 푼다

갤러리 n 이 CLOSED 가 되면 Lambda 가 job.run_train 을 돈다. 마감된 라벨 갤러리 전부를 모아 먼저 홀드아웃을 재고, 그 다음 전부를 한 표로 합쳐 벡터를 새로 푼다. 이전 벡터는 버린다. 갤러리 하나가 아니라 누적 데이터가 모델이므로 페이로드의 galleryId 는 로그용이다. 학습 자체는 갤러리 8 실측에서 0.06초 — 시간은 대부분 DB 읽기다.

순서 — 시험이 학습보다 먼저다

한다마감 갤러리를 모아 ① 읽기 → ② 홀드아웃·게이트 → ③ 전체 학습 → ④ 저장. 게이트를 통과한 실행만 active.왜홀드아웃은 아직 학습에 넣지 않은 갤러리에서, 넣기 직전에 재야 한다. 학습에 들어간 갤러리에서 재면 자기가 배운 것을 다시 푸는 것이라 점수가 부풀려진다(v1 실측: in-sample 0.86 vs 하나 빼고 0.55). 그래서 ②가 ③보다 앞이다.없으면매번 "잘 맞는다"는 점수만 남고, 새 부부에게 실제로 도움이 되는지 알 수 없는 채로 추천에 붙는다.입출력run_train(store, settings, gallery_ids?) → {status, model_id, stored, n_galleries, n_positives, lambda, active, gate{…}, elapsed_s}
  1. 읽기. list_closed_galleries() — galleries.status='CLOSED' 이고 삭제 안 된 선택이 1장 이상 있고 photo_analysis.model_version 이 채워진 갤러리, 마감 순. 갤러리마다 read_gallery(사진·분석 전체 행)와 read_selected(선택 photo_id). 선택이 재료 안에 없으면 그 갤러리는 건너뛴다. 갤러리들의 embedding_model · model_version 이 섞여 있으면 한 행에 담을 수 없으므로 중단.
  2. 시험. evaluate.gate — leave-one-gallery-out 으로 갤러리마다 성적 한 줄, 쌓인 줄로 세 조건 판정. 갤러리 2개 미만이면 "측정 불가"를 이유에 적고 통과시키지 않는다. 상세는 4.
  3. 학습. train.train — 갤러리 n 개의 라벨 표본을 이어 붙여 로지스틱 회귀 한 번. λ(n) 도 여기서 계산.
  4. 저장. store.write_model — holdout 에 verdict, active 에 passed 를 넣어 INSERT. passed 면 같은 트랜잭션에서 UPDATE … SET active=false WHERE active 를 먼저. 테이블이 없으면 None 을 돌려주고 CLI 는 out/preference/models/ 에 JSON 으로 남긴다.
헷갈리기 쉬운 점 둘
갤러리별 벡터는 없다. "갤러리 1 벡터, 2 벡터를 합쳐 하나로"가 아니다. 데이터를 합친 뒤 벡터를 한 번 푼다. 갤러리별로 풀면 각 벡터가 그 부부의 30장을 외우고, 합쳐도 외운 것의 평균이다. 한 표로 풀면 부부마다 다른 취향은 서로 상쇄되어 벡터에 들어가지 못하고 여러 부부에게 공통인 방향만 남는다. 그래서 결과는 "부부 평균 취향"이다.

홀드아웃은 학습하지 않는다. 재기만 한다. 홀드아웃에서 나오는 것은 벡터가 아니라 점수 한 줄이다. 시험은 언제나 학습에 넣지 않은 갤러리에서 본다.

라벨 규칙 — make_sample

한다갤러리 하나의 사진을 양성·음성·라벨 없음으로 나누고 표본 가중치를 매긴다.왜연사 클러스터 안의 사진들은 거의 같은 벡터다. 부부가 그중 한 장만 골랐다고 형제들에 음성을 주면, 없는 경계를 억지로 그리게 되어 학습이 망가진다. 클러스터를 단위로 라벨을 주면 이 문제가 사라지고 양성·음성 불균형도 함께 완화된다.없으면사진 단위로 라벨을 주면 양성 30 대 음성 7,000 의 불균형 위에 형제 컷의 모순 라벨이 얹힌다.입출력LabeledGallery → Sample{idx, y, w}
정의가중치왜
양성부부의 최종 선택(photo_selection_items). 골든 데이터에서는 A컷·B컷 모두같은 연사 클러스터에 둘 이상이면 1/count — 클러스터당 합 1한 장면을 여러 장 골랐다고 그 장면이 여러 배 중요해지지 않게
음성양성이 없는 연사 클러스터의 대표 1장(cluster_rank 0, 없으면 첫 행). 단독 사진은 자기만의 클러스터클러스터당 1클러스터 대표만 — 형제끼리 중복 라벨을 막고 불균형도 완화
라벨 없음양성의 연사 형제—거의 같은 벡터에 반대 라벨을 주면 없는 경계를 그리게 된다

클래스 가중치는 양성 합 0.5 · 음성 합 0.5 (balanced). 갤러리마다 표본 가중치 합이 1 이라 큰 갤러리가 지배하지 않는다. 양성이 하나도 없거나(선택이 재료 밖) 음성이 없으면(모든 클러스터에 선택이 있음) ValueError.

모델 — 두 강도 L2 로지스틱 회귀

한다가중 로지스틱 손실 + λ_s‖w_s‖² + λ_e‖w_e‖² 를 scipy L-BFGS-B 로 푼다. bias 는 정규화하지 않는다. torch 없음.왜갤러리당 양성이 수십 개인데 임베딩은 1,536차원이라 정규화 없이는 외운다. 스칼라(11)는 약하게, 임베딩은 강하게 두 강도로 누른다. 그리고 정규화 강도를 블록의 분산 규모로 보정한다 — 임베딩 1,536차원은 좌표당 분산이 1/1536 수준이라 보정 없이 l2·‖w‖² 을 쓰면 값의 뜻이 차원 수에 묻힌다.없으면l2 손잡이 하나로는 스칼라를 살리면 임베딩이 외우고, 임베딩을 누르면 스칼라가 죽는다.입출력fit(xs, xe, y, w, knobs) → (w_scalar, w_emb, bias)
reg = [ l2_scalar · trace(Cov(x_s))/11 ] × 11  ⊕  [ l2_emb · trace(Cov(x_e))/1536 ] × 1536  ⊕  [ 0 ]   # bias
loss(θ) = Σ w_i · ( log(1 + e^{m_i}) − y_i·m_i ) / Σ w_i  +  Σ reg_j · θ_j²        m = X θ
θ* = L-BFGS-B(θ₀ = 0, maxiter 500)   →   w_scalar = θ[:11], w_emb = θ[11:1547], bias = θ[-1]

l2_emb0.1PREF_L2_EMB임베딩 블록 L2 (강하게)
n05.0PREF_N0λ(n) = n/(n+n0)
k_multiplier3—recall@K 의 K = 3 × 양성 수
gate_p · gate_worse_ratio · gate_stability_window · gate_stability_tol0.05 · 0.30 · 3 · 0.05—게이트 3조건

sanity — 학습이 아니라 파이프라인 확인

run_sanity(gallery_id, selected_ids) 는 갤러리 하나를 in-sample 로 학습하고 같은 갤러리를 재정렬해 양성이 후보 범위(K)에 드는지 본다. 성능 지표가 아니다 — 1,547차원이 30장을 외우므로 당연히 든다. 특징 조립·라벨·학습·dedup 순위가 끝까지 도는지를 보는 것이고, prior 단독 값을 함께 남겨 훗날 비교의 첫 줄로 쓴다. 통과 기준은 pref.recall_cluster ≥ 0.999. 갤러리 8 결과는 4.
