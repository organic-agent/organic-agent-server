preference_models — 가중치 행 (V14, #162)

실행마다 한 행 INSERT, 지우지 않는다. 그래서 테이블 자체가 "갤러리 수를 늘려가며 홀드아웃 지표를 누적 기록"하는 표다. 쓰는 주체는 preference Lambda(photoselect role, SELECT·INSERT·UPDATE GRANT), wes 는 읽기만(목표).
