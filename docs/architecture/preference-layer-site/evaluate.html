평가와 게이트 — 새 부부에게 나아졌을 때만 붙인다

평가는 "추천 후보 범위 안에 부부가 고른 사진이 얼마나 들어오나"(recall@K)를 추천이 실제로 보여주는 순위에서 잰다. 학습에 안 쓴 갤러리에서만 재고(leave-one-gallery-out), prior 단독과 융합의 쌍 차이의 부호로 판정한다. 개선 폭이 완만할 것이라 절대값이 아니라 부호를 본다. 갤러리 수는 고정하지 않고 늘려가며 본다.

preference/evaluate.py(dedup_order · recalls · auc · evaluate_gallery · logo · paired_diff · sign_test · gate) · config.Knobs

gate 한 번 — 갤러리 n개로 verdict 한 줄

지표 — dedup 한 순위에서 잰다

한다점수식마다 갤러리 사진을 정렬하되 연사 클러스터당 최고점 1장만 남긴 뒤 상위 K 를 본다. K = 3 × 양성 수.왜wes MmrSelector.bestPerCluster 가 그렇게 보여주기 때문이다. 갤러리 8 실측에서 양성 30장의 클러스터가 합쳐 1,109장(중앙값 35)이라 dedup 없이는 형제가 상위를 채워 지표가 노출과 어긋난다.없으면"상위 90 안에 들었다"가 화면에서 보이는 90장과 다른 뜻이 된다.입출력recalls(scores, pos, k, cluster_id) → (strict, cluster) · auc(scores, pos, neg)
지표정의쓰임
recall@K strict양성 그 사진이 클러스터 대표로 상위 K 에 올라온 비율참고. 형제 컷 중 어느 장인지는 이 특징으로 못 가르므로 낮은 게 정상
recall@K cluster양성의 클러스터가 상위 K 에 든 비율 — 실제 노출과 맞는 쪽게이트 · sanity 기준
AUC(양성, 음성 대표) 쌍 중 양성 점수가 큰 비율. 동점 0.5쌍 예측 정확도 참고

세 점수식을 나란히 잰다: prior = z(0.5·tech + 0.5·aes) · pref = z(w·x + b) · fused = z(prior) + λ·z(pref). 게이트 비교는 fused − prior 다.

leave-one-gallery-out

logo(galleries) — 갤러리 i 를 빼고 나머지로 학습해 i 에서 평가, i = 1..n. 갤러리 2개 미만이면 빈 목록(측정 불가). 특징은 갤러리마다 한 번만 조립해 n 번의 학습에 재사용한다. 갤러리 안에서 사진을 나누어 홀드아웃하지 않는 이유: 같은 부부·같은 촬영이라 낙관 편향이 생긴다. 새 부부에게 옮겨지는가가 질문이므로 단위는 갤러리다.

게이트 — active 조건 셋

한다홀드아웃 줄들로 세 조건을 모두 만족할 때만 passed=true. 모자라면 이유를 적고 통과시키지 않는다.왜이 층은 부부 평균만 배우므로 개선 폭이 완만할 것이다. 평균 recall 이 0.02 올랐다는 절대값은 잡음과 구분되지 않는다. 대신 "갤러리 대부분에서 나빠지지 않고 더 나아졌는가"를 부호로 묻고, 갤러리가 늘 때 성적이 무너지지 않는지(안정성)까지 본다.없으면갤러리 하나가 우연히 잘 맞은 실행이 active 가 되어 다른 부부의 추천을 흔든다.입출력gate(galleries, knobs) → {metric, n_galleries, passed, reasons[], rows[], curve[], mean_diff, p_value, worse_ratio, prior_mean, fused_mean}
  1. 부호 검정. diff = fused − prior (recall_cluster) 의 갤러리별 부호로 단측 이항검정(개선). 동점 제외. p ≥ 0.05 면 실패. 갤러리 5개부터 유의할 수 있고 6개면 5/6 우연(11%)에도 열리므로 갤러리 수를 고정하지 않고 늘려가며 본다.
  2. 악화 비율. diff < 0 인 갤러리 비율이 0.30 을 넘으면 실패. 평균이 좋아도 셋 중 하나가 나빠지면 안 붙인다.
  3. 안정성. 최근 3회 갤러리 추가에서(접두 크기 n−3..n 별 LOGO) 평균 차이가 0.05 넘게 줄면 실패. 갤러리 하나가 바꾸는 recall 폭이 1/m 이라 허용치를 0 으로 두면 잡음에 걸린다. 갤러리 5개 미만이면 "안정성 판단 불가".
n < 2측정 불가 → 2 ≤ n < 5홀드아웃 줄은 쌓이지만 안정성 판단 불가 → n ≥ 5세 조건 판정 → passed 면 active
