RDS PostgreSQL 하나, S3 버킷 셋

모든 상태는 RDS PostgreSQL 16.14 한 대(db.t4g.micro, Single-AZ)에 있고, 사진 바이트는 S3 사진 버킷에 galleries/{galleryId}/… 원본과 previews/ 미리보기로 놓입니다. 환경은 키가 아니라 버킷으로 갈리며, 로컬 개발은 같은 모듈로 만든 dev 버킷을 씁니다. DB 계정 넷은 전부 Terraform 밖에서 손으로 만들고 비밀번호는 SSM SecureString에만 있습니다.

Terraform이 만드는 SSM 값은 spring.datasource.url(?sslmode=require)과 spring.datasource.username 둘입니다. RDS 서브넷 그룹은 2 AZ가 필수라 DB 서브넷이 두 곳이지만 인스턴스 자체는 한 AZ에만 있습니다.

DB 계정과 커넥션 상한
