admin.easyselect.kr — 공개 경로를 우회하는 tailnet 전용 호스트

BackOffice와 비공개 관리자 API는 인터넷에서 닿을 수 없는 EC2 wes-admin 한 대에 있습니다. SG 인바운드는 0이고, Tailscale에 등록된 기기만 tailnet :443으로 들어옵니다. 호스트 안에서는 Tailscale Serve → Caddy(Let's Encrypt DNS-01) → BackOffice BFF → wes-admin-api :8081로 흐르고, 컨테이너는 외부 라우팅이 없는 Docker 네트워크로 격리됩니다. 공개 ALB는 /internal/admin*을 404로 고정합니다.

아키텍처

Tailscale

  1. 노드 등록. 부팅 시 SSM /wes/admin/tailscale-auth-key(수동 SecureString, /wes/prod/ 밖으로 검증)를 한 번 읽어 tailscale up --hostname=wes-admin --advertise-tags=tag:wes-admin --accept-dns=false --accept-routes=false. 키는 state에 없습니다.
  2. Serve. tailscale serve --bg --tcp=443 tcp://127.0.0.1:8443 — raw TCP 전달. Funnel(공개 노출)도, *.ts.net 인증서도 쓰지 않습니다. TLS는 Caddy가 admin.easyselect.kr 이름으로 끝냅니다.
  3. ACL grant. src: autogroup:member + autogroup:tagged → dst: tag:wes-admin, ip: tcp:443. tagOwners는 관리자 계정 하나. 정책 테스트가 22·8080·8443 거부를 확인합니다(tailscale/wes-admin-policy.hujson.example).
  4. DNS. admin.easyselect.kr A → Tailscale IPv4 100.88.250.104(변수 admin_tailscale_ipv4, CGNAT 대역 검증, null이면 레코드 미생성). 공개 DNS에 사설 IP가 실리지만 tailnet 밖에서는 도달할 수 없습니다.

Caddy · TLS

부팅 때 xcaddy build v2.10.2 --with github.com/caddy-dns/route53@v1.6.0로 빌드해 호스트 systemd(사용자 caddy, ProtectSystem=strict)로 띄웁니다. 사이트는 https://admin.easyselect.kr:8443 하나, bind 127.0.0.1, tls { dns route53 }로 Let's Encrypt DNS-01 발급(위 롤 정책), reverse_proxy 172.30.0.10:8080. 관리 API·HTTP 리다이렉트는 껐습니다. HTTP-01이 아니라 DNS-01인 이유는 :80이 인터넷에 열려 있지 않기 때문입니다.

BackOffice · admin-api

  • BackOffice (Next BFF). 컨테이너 :8080, 호스트 포트 publish 없음. Caddy만 172.30.0.10:8080으로 닿습니다. 업스트림은 ADMIN_API_BASE_URL=http://wes-admin-api:8081. 별도 repo(organic-agent-backoffice)의 CD가 배포.
  • wes-admin-api (Spring Boot). :8081(admin_api_port, 8080과 다름을 검증), 127.0.0.1:8081만 publish(헬스용). SG·Caddy·ALB 어디에도 열려 있지 않습니다. DB 계정 wes_admin_api, spring.flyway.enabled=false, ddl-auto=validate. 서버 repo의 wes-admin-api-deploy-* 롤이 배포.
  • 두 CD의 직렬화. 같은 호스트에 두 저장소의 CD가 오므로 둘 다 flock -w 600 /var/lock/wes-admin-deploy.lock을 잡습니다. 두 OIDC 롤 모두 ssm:SendCommand를 태그 Name=wes-admin으로 제한.

SSM prefix /wes/admin-api/prod/*

앱 prefix와 분리(validation)되어 있어 wes-app 롤은 못 읽고 wes-admin 롤은 /wes/prod/*를 못 읽습니다. Terraform이 만드는 값은 전부 String이고 비밀번호만 수동 SecureString입니다.
