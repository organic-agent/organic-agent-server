읽을 때 기억할 규칙

  • 소유 단위는 워크스페이스. studios · galleries · workspace_members · studio_invites 가 전부 workspace_id 로 매달리고 CASCADE 다. studio_members 테이블은 없다.
  • 부부는 두 곳에 산다. 스튜디오 갤러리에서는 gallery_members(정원 2), 개인 갤러리에서는 workspace_members(MEMBER). 정책이 둘을 "참가자"로 합친다.
  • 행의 존재가 사실인 테이블. gallery_members(수락), collab_photo_likes(좋아요), photo_ratings(별점 있음). 값 컬럼이 없거나 하나다.
  • 계약 숫자는 galleries 에. 장수·마감·보정 횟수·플랜을 갤러리 컬럼이 들고, 셀렉·보정·업로드가 같은 값을 본다.
  • 선행 컬럼. retouch_rounds 네 컬럼, retouch_photos.structured_ai_metadata, ai_recommendations.accepted_at 계열은 스키마에만 있다.
