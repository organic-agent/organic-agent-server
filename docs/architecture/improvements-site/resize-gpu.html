업로드는 브라우저가 줄이고, 점수는 GPU가 집어 간다

두 개선은 서로 다른 단계를 건드립니다. 긴 변 2048 리사이즈는 업로드(63.5분 → 4.6분)와 embedder를 가볍게 했고, score GPU 워커는 score만(장당 1.5초 → 0.04초, 7,189장 $1.6 → $0.13) 바꿨습니다. score는 embedder가 만든 1024px 미리보기만 읽으므로 2048 마스터의 영향을 받지 않습니다(upload-master-2048 §3.4 "변경 없음. preview만 읽는다"). 이 페이지는 둘을 한 곳에 두되 영향 범위를 분리해 적습니다.

폐기된 대안. ARNIQA 입력 해상도를 낮춰 score를 줄이는 시도는 896/768/640px에서 Spearman 0.638/0.536/0.479로 떨어져 버렸다(score-speedup §4.4 L137–146). 점수를 빠르게 하려면 픽셀을 줄일 게 아니라 연산 장치를 바꿔야 했다 — 그것이 ②다.
