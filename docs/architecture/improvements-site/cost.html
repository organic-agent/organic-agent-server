읽어낼 것

  1. 변동비의 절반 이상이 추천 이유 문장이다. 30장 추천 한 번($0.34)이 7,200장 파이프라인 한 번($0.45)과 같은 자릿수. 파이프라인은 GPU 전환으로 이미 1/4.3이 됐고, 다음 비용 레버는 이유 문장의 이미지 수다.
  2. 월 100갤러리까지는 고정비($145)가 변동비보다 크다. 갤러리당 총원가 $16.8(10개) → $4.3(100개). 고정비 중 테스트 프론트·IPv4·모니터링 등 $40 안팎은 선택이다.
  3. S3는 저장보다 전송이 먼저 커진다. 저장 $0.089/갤러리/월 vs 열람 전송 최대 $0.74/갤러리. 단, 저장은 지우지 않는 한 누적되고 보관 정책이 없다.
  4. 실측이 없는 항목 넷. 질의 해석 토큰, 열람 전송량, 미리보기 실제 크기 합, CloudWatch. 앞의 둘은 로그(bedrock … in/out tokens)와 S3 요청 지표로 잴 수 있다.
